# Bug sweep and release controls — 2026-11-13

## Corrected
The first reconciliation implementation used a loose `https://` prefix, a date-shaped string, and treated exact course-title matches as `enrich_existing`. That could encourage inappropriate enrichment without validating campus, qualification, regulator status or evidence freshness. The replacement uses the shared validation gate, deduplicates aliases by institution ID, rejects future and impossible dates, and always marks matches for manual review. Matching an existing course is `possible_existing_offering`, never an instruction to overwrite.

## Still to verify before release

- Browser and accessibility tests for redesigned Decide and other student-facing screens. CSS prototypes are opt-in only.
- Canonical data expansion against current primary sources; none has been fabricated or auto-imported.

## Release policy
No merge or production deployment while these gates remain unresolved. Avoid branch preview builds by configuring Netlify build settings, not by assuming that a branch push has no build cost.
