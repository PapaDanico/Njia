# Research-grade catalogue indicators

Run `node tools/catalogue-indicators.mjs --out catalogue-indicators.json` from repository root. This reads canonical `data/courses.js`, `data/institutions.js` and **the actual `feeBasis()` implementation** from `js/decide.js`; it never edits site files or creates unverified records.

## Indicator definitions
- **Offerings:** course records, not unique programmes or verified active intakes.
- **Distinct programme names:** normalised text names, not qualifications verified by a regulator.
- **Institutions with offerings:** unique institution IDs linked from the course records.
- **County coverage:** counties represented in the catalogue, not comprehensive national coverage.
- **Published fee share:** published-classified course offerings / all offerings with linked institutions.
- **Unavailable fee share:** linked offerings with `total_fees_kes === null` / all linked offerings; never interpreted as free.
- **Open entry:** null `min_grade` per Njia's existing semantics; no admission guarantee.
- **No employment rates, admissions probabilities or labour-market outcomes are inferred.**

## Product integration
Treat these statistics as a transparent research appendix, not claims of national supply. Display denominator, source (Njia canonical catalogue), data freshness date and limitations alongside each chart. Existing landing-page counts remain generated by `tools/build-landing-stats.mjs`; do not hand-code replacement figures. Do not publish this report until it is wired into a dated generated artefact with freshness tests.
