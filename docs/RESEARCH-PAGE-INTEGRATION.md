# Research page deployment integration

`research/index.html` and `research/research.js` provide an accessible, source-limited catalogue statistics interface, designed in Njia's original academic-editorial visual system. It requires `research/catalogue-indicators.json`, generated by `node tools/catalogue-indicators.mjs --out research/catalogue-indicators.json` **in the release build**.

Do not publish the page as complete before the JSON exists and its freshness is checked. The page fails closed with a visible availability notice rather than inventing values.

Next: wire the generator into the established build/test workflow, check the canonical catalogue's actual data schema, then link the page in navigation. The JSON is intentionally not hand-generated in this commit.
