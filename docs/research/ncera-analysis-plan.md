# NCERA statistical analysis plan — pre-registration draft

**Not pre-registered; no study data collected.** This is a planning skeleton requiring a named statistician and ethics review.

## Hypotheses
H1: structured Njia guidance improves a blinded career-decision quality rubric at 4–8 weeks relative to usual guidance.
H2: improvements in occupational knowledge and source-checking mediate some intervention effect (exploratory; do not claim causal mediation without assumptions).
H3: item structure, reliability and interpretation are acceptably stable across major intended learner cohorts (to be tested, not assumed).

## Primary endpoint
Rubric score across accurate occupation knowledge, verified entry route, affordability awareness, alternatives and next action. Fix scoring anchors and inter-rater agreement thresholds before recruitment. Select a minimally important difference with counsellors and learners.

## Design
Prefer cluster randomisation with schools/centres as units; account for intracluster correlation, cluster number, baseline score, attrition and differential access. If observational, pre-specify matching variables, balance diagnostics and sensitivity to unmeasured confounding.

## Psychometrics
Ordinal EFA in development set, independent CFA, omega with confidence intervals, test-retest, DIF and measurement invariance. Define missing-response rules and 'not familiar' handling before scoring. No norms from convenience samples.

## Inference
Intention-to-treat, multilevel models or cluster-robust inference, 95% confidence intervals, multiplicity plan for secondary endpoints, transparent null/negative reporting. Pre-specify subgroup contrasts only when powered. Report recruitment, missingness and protocol deviations.

## Power and sample size
Do not use the illustrative 300–500 / 1,000–1,500 targets as statistical justification. Calculate sample sizes after choosing endpoint SD, clinically/educationally meaningful difference, ICC, clusters, expected attrition, factor item counts and invariance groups.

## Data governance
De-identified analysis datasets; separate contact data if follow-up is consented; no minors' identifiable responses in GitHub; publish aggregate reproducible analysis only.
