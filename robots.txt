# Njia — https://njiacareerpathways.work/
#
# Njia exists to be found by Kenyan school leavers deciding what to do next.
# Until this file existed there was no crawl invitation and no sitemap
# pointer, and a search for the domain returned nothing at all.
#
# Everything here is public, free and requires no account, so everything is
# crawlable. There are no private routes to exclude: the app is a single
# page, all state lives in the visitor's own browser, and nothing a user
# enters is ever sent to a server.

User-agent: *
Allow: /

# The one exclusion, and it is not about privacy.
#
# /m/ holds milestone markers — empty-of-meaning text files that exist only to
# be requested when a reader finishes the questionnaire, saves a course, starts
# an application or downloads a report. The count of those requests is the only
# usage measurement Njia takes.
#
# A crawler fetching them would be indistinguishable from a young person
# reaching that step, so an indexed /m/ would report enthusiasm that is really
# just Googlebot. Excluded to keep the numbers honest, not to hide anything:
# the files say plainly what they are, and anyone may read them.
Disallow: /m/
